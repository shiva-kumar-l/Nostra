# Nostra
# 🌐 Responsive Fashion Website

A modern and fully responsive fashion website built using **HTML5**, **CSS3**, and **Vanilla JavaScript**. The project consists of multiple pages with interactive features such as **product search** and **category filtering**, providing users with a smooth browsing experience across desktop, tablet, and mobile devices.

---

## 📌 Features

* 🏠 Responsive Home Page
* 👕 Collections Page with product listings
* 📞 Contact Us Page
* 🔍 Real-time Search functionality
* 🎯 JavaScript-based Product Filter
* 📱 Mobile-friendly responsive design
* ✨ Clean and modern user interface
* ⚡ Fast and lightweight (No external frameworks)

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)
